# しごとボード（SHIGOTO BOARD）

鉄道の発車標をモチーフにした、若手社会人向けの業務アシスタント。
会議メモをAIで構造化し、ToDoを「発車標」で管理し、記録・日誌から振り返りや報告文を自動生成します。

## 機能一覧

| 路線 | 機能 |
|---|---|
| 運行 | タスク発車標（期限順・遅延／まもなく／定刻）、到着案内（人に依頼したことの管理・催促推奨）、手動追加・完了・戻す |
| 取込 | 会議メモのAI構造化（会議名・論点・決定事項・ToDo・依頼・用語の自動抽出）、資料・ニュースの要約収蔵（第二の脳） |
| 記録 | 議事録・資料のアーカイブ、キーワード検索、記録への質問（AI回答）、会議前の予習ブリーフ生成 |
| 日誌 | 業務日誌（一日数行）、指摘ログ、週次振り返り自動生成、期間指定の面談用サマリ（1on1・評価面談準備） |
| 文書 | 状況別の文面下書き（報告・謝罪・催促・相談）、完了ToDoからの報告文生成、到着案内からの催促文ワンタップ生成 |
| ノート | 社内用語・人物ノート（取込時にAIが候補を自動提案） |
| 設定 | APIキー・モデル設定、データのJSON書き出し／読み込み、全削除 |

## 漏洩対策（送信ゲート）

AI機能を使う際も、情報が無断で外に出ない三段構えになっています。

1. **完全オフラインモード**（設定タブ） — AIへの送信を一切遮断。タスク管理・日誌・検索はすべて動作。漏洩リスクを確実にゼロにしたい場合はこちら。
2. **自動マスキング** — 送信前に端末内で、人名（敬称つき）・会社名・金額・メール・電話番号・NGワード辞書の語・人物ノートの名前を【人物1】【会社1】等に置換。対応表は端末内にのみ保持され、AIの回答は端末内で元に戻ります。
3. **送信前プレビュー（既定でON）** — マスキング後の全文を表示し、承認しない限り1文字も送信されません。

※ サービスワーカーや配信サーバーはデータに一切触れません（静的サイト。データはブラウザ内のみ）。

## 使い方

### サイト／アプリとして（推奨）

GitHub Pages で配信できます（`.github/workflows/deploy.yml` 同梱）。

1. リポジトリの Settings → Pages → Source を **GitHub Actions** にする
2. `main` ブランチにマージすると自動デプロイ
3. 公開URLをスマホ・PCで開き、「ホーム画面に追加／アプリとしてインストール」するとPWAアプリとして動作（オフライン起動対応）

### 単一ファイルとして（社内PCなど、開発環境がない場合）

1. `release/shigoto-board.html` をダウンロードして、ブラウザ（Chrome/Edge）で開くだけで動きます。インストール不要。
2. 「設定」タブで Anthropic APIキー（`sk-ant-…`）を登録。
3. データはブラウザの localStorage に保存されます（閉じても消えません）。定期的に「設定 → JSONに書き出す」でバックアップしてください。

※ AI機能は `api.anthropic.com` への通信が必要です。社内ネットワークで遮断されている場合、AI機能は使えません（タスク管理・日誌・アーカイブ検索はオフラインでも動作）。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # dist/index.html に単一ファイルとしてビルド
```

ビルド後、`cp dist/index.html release/shigoto-board.html` で配布用ファイルを更新します。

## 技術構成

- React 18 + Vite（`vite-plugin-singlefile` で単一HTMLにバンドル）
- `@anthropic-ai/sdk`（ブラウザ直接呼び出し）。会議メモ構造化は構造化出力（JSON Schema）で堅牢にパース
- 既定モデル: `claude-opus-4-8`（設定で Sonnet 5 / Haiku 4.5 に変更可）
- 永続化: localStorage（JSONバックアップ機能つき）

## セキュリティ上の注意

- AI機能利用時、マスキング後のテキストは Anthropic API に送信されます。**会社の生成AI利用ガイドラインを確認のうえ利用してください。** 確実にゼロにしたい場合は完全オフラインモードを使ってください。
- マスキングは自動検出（人名・会社名・金額・連絡先）+ 辞書方式です。検出漏れに備えて送信前プレビューで必ず目視確認してください。
- APIキーとデータは端末のブラウザ内にのみ保存されます。共用PCでの利用は避けてください。
- AI生成の文面は必ず自分で確認・修正してから送信してください。
